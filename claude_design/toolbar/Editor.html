CIFS

Protocols / Networking·Last edited 19m ago

CIFS (Common Internet File System) is a network file-sharing protocol that lets applications read and write to files and request services from server programs across a network. It is a public, platform-independent dialect of SMB (Server Message Block).

How it works

A client issues requests to a server to open, read, write, and close files over TCP/IP — typically on port 445. The server authenticates the session, then brokers concurrent access so multiple clients can share the same files safely.

  • Transparent access to remote files as if they were local
  • Record- and file-level locking to prevent conflicting writes
  • Read-ahead and write-behind caching for performance
